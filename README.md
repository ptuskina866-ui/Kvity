# «Квиты» (Kvity) — MVP совместных расходов и деления чеков

Легкий и быстрый сервис деления чеков и совместных расходов без регистрации (**Zero-login**), работающий как автономное **PWA** (Progressive Web App) и как **Telegram Mini App** (TMA).

---

## ⚡ Ключевые возможности

1. **Zero-login**: Никаких логинов, паролей и SMS. Сбор доступен по уникальному криптостойкому токену в URL (nanoid, 10–12 знаков).
2. **Адаптация под СНГ**:
   - Валюты: **BYN**, **RUB**, **USD**, **EUR**, **KZT**
   - Поле реквизитов для каждого участника: номер банковской карты, телефон для **СБП** или **ЕРИП**
   - Копирование реквизитов получателя в 1 клик с тактильным откликом.
3. **Telegram Mini App (TMA)**:
   - Раскрытие на весь экран (`expand()`)
   - Автоподтягивание имени пользователя (`user.first_name`)
   - Адаптация под тему Telegram через CSS-переменные (`--tg-theme-*`)
   - Тактильная отдача **HapticFeedback** при сохранении трат и копировании
   - Кнопка **«Сформировать отчет для чата»** — копирует готовый текст для отправки в Telegram.
4. **PWA и Оффлайн**:
   - Манифест `manifest.json` и Service Worker `sw.js`
   - Локальный кэш `localStorage` для просмотра сбора без интернета
   - Установка как мобильное приложение на экран смартфона.
5. **Алгоритм Min Cash Flow**:
   - Жадный алгоритм минимизации взаимных транзакций
   - Исключает циклические переводы (например, A должен B, B должен C, C должен A)
   - Точный расчет долей с учетом копеек.

## 🚀 Быстрый запуск

### Вариант 1: Встроенный сервер PHP (рекомендуется для разработки)

Требуется PHP 8.2+ с включенным модулем `pdo_sqlite` (по умолчанию включен).

```bash
# Перейдите в папку проекта
cd d:\Kvity

# Запустите встроенный PHP сервер
php -S 0.0.0.0:8000 -t public public/index.php
```

Откройте браузер по адресу: **http://localhost:8000**

База данных SQLite (`database/kvity.sqlite`) создается автоматически при первом обращении.

---

### Вариант 2: Использование MySQL

1. Создайте базу данных `kvity` в MySQL:
```sql
CREATE DATABASE kvity CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```
2. Выполните DDL дамп из `database/schema.sql`.
3. Укажите параметры в переменных окружения или отредактируйте `config/database.php`:
   - `DB_CONNECTION=mysql`
   - `DB_HOST=127.0.0.1`
   - `DB_DATABASE=kvity`
   - `DB_USERNAME=root`
   - `DB_PASSWORD=ваш_пароль`

## 📡 REST API Эндпоинты

| Метод | URL | Описание |
|---|---|---|
| `POST` | `/api/rooms` | Создать сбор (`title`, `base_currency`, `participants`) |
| `GET` | `/api/rooms/{slug}` | Получить данные комнаты, участников и расходов |
| `POST` | `/api/rooms/{slug}/participants` | Добавить участника или обновить его реквизиты |
| `POST` | `/api/rooms/{slug}/expenses` | Добавить расход с точным сплитом долей |
| `DELETE`| `/api/rooms/{slug}/expenses/{id}` | Удалить расход |
| `GET` | `/api/rooms/{slug}/balances` | Рассчитать взаиморасчеты (Min Cash Flow) |
